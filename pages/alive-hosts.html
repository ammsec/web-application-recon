Phase 3 — Active Probing & Verification

Confirm which of the subdomains you found are actually alive and serving HTTP/HTTPS. No point spending time on dead hosts — filter down to what's live and focus there.

Why this phase matters

Subdomain enumeration usually returns hundreds or thousands of names, but many resolve to nothing or are long dead. This phase turns that raw list into a short, verified set of live targets — complete with status codes, page titles, and detected technology — so every phase after this one works with real, reachable hosts.

httpx Go · Industry Standard

What it does: Sends an HTTP request to every host in a subdomain list and verifies which ones are live. Returns status code, page title, detected technology stack, and can capture screenshots.

GitHub ↗

Installation

go install -v github.com/projectdiscovery/httpx/cmd/httpx@latest

# Verify
httpx -version

Usage

# Basic — filter down to live hosts
cat subdomains.txt | httpx

# Title, status code, tech detect (best all-round command)
cat subdomains.txt | httpx -title -status-code -tech-detect

# Check multiple ports
cat subdomains.txt | httpx -title -status-code -tech-detect -p 80,443,8080,8443,8888

# Subfinder piped straight into httpx
subfinder -d target.com -silent | httpx -title -status-code -tech-detect -o live_hosts.txt

# Full pipeline: Subfinder → dnsx → httpx
subfinder -d target.com -silent | dnsx -silent | httpx -title -status-code -tech-detect -o live_hosts.txt

# Screenshot live hosts (requires gowitness)
httpx -l subdomains.txt -screenshot

# JSON output
httpx -l subdomains.txt -json -o results.json

# Filter by specific status codes
httpx -l subdomains.txt -mc 200,301,302,403
gowitness Go · Visualization

What it does: Takes a screenshot of every live host and builds an HTML report from them, making it much faster to manually review a large host list at a glance.

GitHub ↗

Installation

go install github.com/sensepost/gowitness@latest

Usage

# Screenshot every host in a file
gowitness scan file -f live_hosts.txt

# View the report
gowitness report serve
# Then open: http://localhost:7171
