API Recon

Modern web apps are mostly APIs behind a frontend. This phase focuses specifically on finding API documentation, undocumented routes, and GraphQL endpoints — surface that generic web recon often walks right past.

Why this phase matters

A JSON API doesn't render like a normal page, so directory brute forcers and crawlers frequently miss most of it. Finding the API's actual route map — often sitting in a forgotten Swagger file or exposed via GraphQL introspection — reveals endpoints that were never meant to be public and were never tested.

Finding API Documentation

Common Doc & Schema Paths Manual Check

What it does: Developers often leave OpenAPI/ Swagger definitions or Postman collections publicly accessible. Check these paths on every live host before anything else. 

# Try these against every live host
/swagger.json
/swagger.yaml
/swagger-ui.html
/openapi.json
/api-docs
/v1/api-docs
/api/swagger.json
/.well-known/openapi.json
/graphql
/graphiql
/postman_collection.json

# Quick batch check with httpx
cat live_hosts.txt | httpx -path /swagger.json,/openapi.json,/api-docs -mc 200
Kiterunner Go · API Route Brute Force

What it does: A content discovery tool built specifically for APIs — brute forces routes using wordlists derived from thousands of real Swagger/OpenAPI specs instead of generic directory wordlists, and understands REST-style path structures.

GitHub ↗

Installation

git clone https://github.com/assetnote/kiterunner.git
cd kiterunner
make build
# Binary ends up at ./dist/kr

Usage

# Scan with a routes wordlist (download from Assetnote's wordlist repo)
kr scan https://target.com -w routes-large.kite

# Scan a list of hosts
kr scan -A live_hosts.txt -w routes-large.kite

# Filter by status codes
kr scan https://target.com -w routes-large.kite -x 400,401,403,404,500

GraphQL Recon

Introspection Query Manual

What it does: If a GraphQL endpoint has introspection enabled (it often is, even in production), a single query dumps its entire schema — every type, query, and mutation the API supports.

Usage

# Send an introspection query with curl
curl -s -X POST https://target.com/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "query IntrospectionQuery { __schema { types { name fields { name } } } } "}'
graphql-cop Python

What it does: Automates common GraphQL security checks — introspection exposure, batching attacks, field suggestion leaks, and CSRF issues — against a single endpoint.

GitHub ↗

Usage

git clone https://github.com/dolevf/graphql-cop.git
cd graphql-cop
pip3 install -r requirements.txt
python3 graphql-cop.py -t https://target.com/graphql

Versioning & Shadow Endpoints

Check every API version, not just the current one

/api/v1/, /api/v2/, /v1/, /internal/, /beta/ — old versions are frequently left running with weaker auth or fewer input checks than the current one. Once you've found one API path, always try swapping the version number and re-running discovery against it.
