Phase 9 — Vulnerability Scanning

Everything collected so far — live hosts, URLs, parameters — feeds into this final phase. Automated scanning turns that raw data into actual, confirmed vulnerabilities.

Why this phase matters

Manual testing doesn't scale to hundreds of live hosts and thousands of URLs. Automated scanners catch the common, well-known issues — known CVEs, misconfigurations, and classic injection points — fast, so manual effort can focus on the interesting edge cases these tools miss.

Nuclei Go · Industry Standard

What it does: Runs community-contributed templates to automatically detect CVEs, misconfigurations, XSS, SQLi, SSRF, and more. The single most-used vulnerability scanner in modern bug bounty work.

GitHub ↗

Installation

go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest

# First run downloads templates
nuclei -update-templates

Usage

# Basic scan against one target
nuclei -u https://target.com

# Update templates regularly
nuclei -ut

# Scan a list of live hosts
nuclei -l live_hosts.txt

# Scan with specific tags
nuclei -l live_hosts.txt -tags xss,sqli,ssrf,lfi
nuclei -l live_hosts.txt -tags cve
nuclei -l live_hosts.txt -tags misconfig

# Filter by severity
nuclei -l live_hosts.txt -severity critical,high

# Set a rate limit (helps avoid WAF blocks)
nuclei -l live_hosts.txt -rl 50

# Save output
nuclei -l live_hosts.txt -o nuclei_results.txt

# Generate a Markdown report
nuclei -u https://target.com -markdown-export ./reports

# Full pipeline: Subfinder → httpx → Nuclei
subfinder -d target.com -silent | httpx -silent | nuclei -tags cve,misconfig -o results.txt
SQLMap Python · Classic

What it does: Automatically detects and exploits SQL injection vulnerabilities, including full database enumeration and dumping.

GitHub ↗

Installation

sudo apt install sqlmap

# OR from source
git clone https://github.com/sqlmapproject/sqlmap.git

Usage

# Basic scan against a URL
sqlmap -u "https://target.com/page?id=1"

# Test all parameters at higher depth
sqlmap -u "https://target.com/page?id=1&name=test" --level=3

# Test a POST request
sqlmap -u "https://target.com/login" --data="username=test&password=test"

# Enumerate databases
sqlmap -u "https://target.com/page?id=1" --dbs

# Dump a table
sqlmap -u "https://target.com/page?id=1" -D database_name --tables

# Use a captured Burp Suite request file
sqlmap -r request.txt

# Batch mode — auto-answer prompts
sqlmap -u "https://target.com/page?id=1" --batch
Ghauri Python · Modern SQLi

What it does: A modern SQLMap alternative with better WAF bypass techniques and support for testing JSON/XML request bodies.

GitHub ↗

Installation

pip3 install ghauri

# OR from source
git clone https://github.com/r0oth3x49/ghauri.git
cd ghauri
pip3 install -r requirements.txt
python3 setup.py install

Usage

# Basic scan
ghauri -u "https://target.com/page?id=1"

# POST data
ghauri -u "https://target.com/login" --data "user=test&pass=test"

# Database dump
ghauri -u "https://target.com/page?id=1" --dbs

# Use a Burp request file
ghauri -r request.txt
Dalfox Go · XSS

What it does: Finds and verifies XSS vulnerabilities in parameters automatically — fast and low on false positives.

GitHub ↗

Installation

go install github.com/hahwul/dalfox/v2@latest

# OR
sudo apt install dalfox

Usage

# Scan a single URL
dalfox url "https://target.com/search?q=test"

# Scan URLs from a file
dalfox file urls.txt

# Scan from a pipe
cat urls.txt | dalfox pipe

# Test a specific parameter only
dalfox url "https://target.com/search?q=test" --only-custom-payload

# Save output
dalfox url "https://target.com" -o xss_results.txt

# Route through Burp proxy
dalfox url "https://target.com/search?q=test" --proxy http://127.0.0.1:8080

Don't forget port-level scanning

These tools focus on web-layer vulnerabilities. For open ports and non-HTTP services, see the Port Scanning page for Nmap usage.
