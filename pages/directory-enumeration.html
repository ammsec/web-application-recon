Phase 5 — Content & Directory Discovery

Find hidden files that were never meant to be public — admin panels, backup files, config files, and forgotten API endpoints.

Why this phase matters

Developers regularly leave things exposed by accident — a .bak or .old file, a leftover config, an admin panel with no auth in front of it. Brute forcing common paths with a wordlist is one of the highest-value, lowest-effort techniques in the entire recon process.

ffuf Go · Industry Standard

What it does: A fast web fuzzer written in Go — fuzzes directories, files, parameters, and headers, all with the same tool.

GitHub ↗

Installation

go install github.com/ffuf/ffuf/v2@latest

# OR
sudo apt install ffuf

Usage

# Basic directory brute force
ffuf -u https://target.com/FUZZ -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt

# With extensions
ffuf -u https://target.com/FUZZ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-words.txt -e .php,.html,.txt,.bak,.js

# Filter out 404s
ffuf -u https://target.com/FUZZ -w wordlist.txt -fc 404

# Filter by response size
ffuf -u https://target.com/FUZZ -w wordlist.txt -fs 1234

# Fuzz a POST request
ffuf -u https://target.com/login -w wordlist.txt -X POST -d "username=FUZZ&password=test"

# Fuzz subdomains
ffuf -u https://FUZZ.target.com -w subdomains.txt -H "Host: FUZZ.target.com"

# Save output as JSON
ffuf -u https://target.com/FUZZ -w wordlist.txt -o results.json -of json

# Route through Burp Suite
ffuf -u https://target.com/FUZZ -w wordlist.txt -x http://127.0.0.1:8080
Feroxbuster Rust · Recursive

What it does: Written in Rust, so it's even faster than ffuf. Recursively scans discovered directories automatically. Very popular in bug bounty workflows.

GitHub ↗

Installation

sudo apt install feroxbuster

# OR via cargo (Rust package manager)
cargo install feroxbuster

Usage

# Basic scan
feroxbuster -u https://target.com

# Custom wordlist
feroxbuster -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/raft-medium-words.txt

# With extensions
feroxbuster -u https://target.com -x php,html,txt,bak,js -w wordlist.txt

# Set thread count
feroxbuster -u https://target.com -t 50 -w wordlist.txt

# Filter by status codes
feroxbuster -u https://target.com -s 200,301,302 -w wordlist.txt

# Route through Burp Suite proxy
feroxbuster -u https://target.com --proxy http://127.0.0.1:8080 --insecure

# Save output
feroxbuster -u https://target.com -o results.txt

# Multiple targets from stdin
cat live_hosts.txt | feroxbuster --stdin
dirsearch Python · Beginner Friendly

What it does: A Python-based directory scanner with a built-in wordlist and simple syntax — a solid starting point if ffuf and feroxbuster feel like too much at once.

GitHub ↗

Installation

pip3 install dirsearch

# OR
sudo apt install dirsearch

Usage

# Basic scan
dirsearch -u https://target.com

# Custom wordlist
dirsearch -u https://target.com -w /path/to/wordlist.txt

# Set extensions
dirsearch -u https://target.com -e php,html,txt,bak

# Multiple targets
dirsearch -l live_hosts.txt

# Save output
dirsearch -u https://target.com -o results.txt
