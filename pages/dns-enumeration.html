DNS Enumeration

Go beyond just finding subdomains — pull full DNS record sets, check for zone transfer misconfigurations, and flag subdomains pointing at services that could be taken over.

Why this phase matters

A domain's DNS records reveal more than just hostnames — mail servers (MX), SPF/DKIM policies (TXT), nameservers (NS), and CNAME chains that sometimes point at a decommissioned third-party service. That last one is how subdomain takeovers happen, and it's one of the easiest high-impact bugs to find once you know what to look for.

dnsx — Full Record Enumeration Go

What it does: Beyond basic resolution, dnsx can pull every DNS record type for a host list in one pass — A, AAAA, CNAME, MX, TXT, NS — plus CDN and ASN metadata.

GitHub ↗

Usage

# Full record recon on a resolved list
dnsx -l subdomains.txt -recon

# Specific record types
dnsx -l subdomains.txt -a -aaaa -cname -mx -txt -ns

# CDN and ASN info (useful for spotting WAF/CDN-fronted hosts)
dnsx -l subdomains.txt -cdn -asn

# Save everything as JSON for later parsing
dnsx -l subdomains.txt -recon -json -o dns_full.json
dig & host CLI · Built-in

What it does: Standard Linux DNS lookup utilities — no install needed. Good for spot-checking a single record or testing a zone transfer manually.

Usage

# Look up all common record types
dig target.com ANY

# MX records
dig target.com MX

# TXT records (SPF, DKIM, verification tokens)
dig target.com TXT

# Attempt a zone transfer (misconfigured servers allow this)
dig axfr target.com @ns1.target.com

# Quick lookup with host
host -t txt target.com
Subdomain Takeover Check nuclei

What it does: A subdomain with a CNAME pointing to an unclaimed third-party service (S3 bucket, Heroku app, GitHub Pages, etc.) can often be claimed by anyone — Nuclei ships dedicated templates to flag these automatically.

Usage

# Run takeover-specific templates against resolved subdomains
nuclei -l subdomains.txt -tags takeover

# Combine with dnsx to only check CNAMEs pointing off-domain first
dnsx -l subdomains.txt -cname -resp-only | nuclei -tags takeover
