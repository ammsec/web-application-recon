Phase 1 — Passive Recon & OSINT

Gather publicly available information about the target without sending any direct traffic to it. This includes IP ranges, ASN data, registration details, and DNS records.

Why this phase matters

Everything here comes from public sources — search engines, DNS databases, certificate transparency logs — so nothing touches the target directly. It's the safest place to start and often reveals infrastructure you wouldn't find any other way.

Online Tools (No Install Needed)

Censys Online

What it does: An internet-wide scanner database that indexes every publicly accessible device and server. Returns ports, certificates, and running services for a target.

search.censys.io ↗

Usage

# Search by domain — returns IP ranges, ports, certificates
"target.com"

# Search by a specific IP
ip:1.2.3.4
Shodan Online

What it does: A search engine for exposed services, open ports, and banners across the internet. Useful for identifying what software a target's servers are running.

shodan.io ↗

Usage

# All subdomains and open ports for a host
hostname:"target.com"

# All IPs owned by a company
org:"Company Name"

# Search by SSL certificate
ssl:"target.com"
DNSDumpster Online

What it does: Maps a domain's DNS records (A, MX, TXT, NS) and subdomains visually, with export support.

dnsdumpster.com ↗

Usage

Enter the target domain on the site to get a DNS map and record list.

Whois CLI + Online

What it does: Shows who registered a domain, when, which registrar, and which nameservers are in use.

whois.com ↗

Terminal

whois target.com
ViewDNS Online

What it does: A collection of DNS lookup utilities in one place — reverse IP lookup, propagation checks, and IP history.

viewdns.info ↗

Useful queries

# Reverse IP — how many domains sit on one IP
Reverse IP Lookup

# Domain's previous IPs — helps find the origin IP behind a CDN/WAF
IP History
