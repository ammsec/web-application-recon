Phase 6 — URL & Endpoint Discovery

Collect every known URL for the target — from live crawling, the Wayback Machine, and other historical sources. This is where hidden endpoints, deprecated APIs, and forgotten admin paths surface.

Why this phase matters

A live crawl only shows what's linked right now. Historical sources remember what used to be linked — old API versions, removed admin panels, parameters nobody bothered to clean up. Combining both gives a far bigger picture of the app's real surface than either alone.

Katana Go · Modern Standard

What it does: A next-gen web crawler that handles modern web apps — parses JavaScript, supports a headless browser mode, and works against SPAs where older crawlers fail.

GitHub ↗

Installation

go install github.com/projectdiscovery/katana/cmd/katana@latest

Usage

# Basic crawl
katana -u https://target.com

# With JavaScript parsing (for JS-heavy apps)
katana -u https://target.com -jc

# Headless mode for dynamic sites
katana -u https://target.com -headless

# Set crawl depth
katana -u https://target.com -d 5

# Save output
katana -u https://target.com -jc -o crawled_urls.txt

# Multiple targets
cat live_hosts.txt | katana -jc -o all_urls.txt

# Limit scope to the root domain
katana -u https://target.com -jc -fs rdn
gau (Get All URLs) Go · Historical

What it does: Pulls historically crawled URLs from AlienVault OTX, the Wayback Machine, Common Crawl, and URLScan. Nothing touches the target directly.

GitHub ↗

Installation

go install github.com/lc/gau/v2/cmd/gau@latest

Usage

# Basic usage
gau target.com

# Save to file
gau target.com > gau_urls.txt

# Filter by extension
gau target.com --o js,php,aspx

# Multiple threads
gau target.com --threads 10

# Include subdomains
gau --subs target.com
waybackurls Go · Historical

What it does: Pulls every URL archived by the Wayback Machine for a domain — great for finding old endpoints and deprecated APIs that are no longer linked anywhere live.

GitHub ↗

Installation

go install github.com/tomnomnom/waybackurls@latest

Usage

# Basic usage
echo "target.com" | waybackurls

# Save to file
echo "target.com" | waybackurls > wayback_urls.txt

# Sort and deduplicate
echo "target.com" | waybackurls | sort -u > unique_urls.txt
hakrawler Go · Simple & Fast

What it does: A simple, fast crawler that quickly extracts links, forms, and JavaScript file references from a live target.

GitHub ↗

Installation

go install github.com/hakluke/hakrawler@latest

Usage

# Basic crawl
echo https://target.com | hakrawler

# Set depth
echo https://target.com | hakrawler -d 3

# Include subdomains
echo https://target.com | hakrawler -subs

# Plain output
echo https://target.com | hakrawler -plain

Combined URL Collection Workflow

All sources → one clean list Workflow

Run all four tools, merge the output, then strip duplicates and static assets that aren't useful for further testing. 

# Collect URLs from every source
echo "target.com" | waybackurls > all_urls.txt
gau target.com >> all_urls.txt
katana -u https://target.com -jc >> all_urls.txt

# Clean up — dedupe, strip images/css
cat all_urls.txt | sort -u | grep -ivE "\.(jpg|jpeg|gif|png|css|woff|woff2|svg|pdf|ico|ttf|eot)$" > cleaned_urls.txt

# Check how many you ended up with
wc -l cleaned_urls.txt
